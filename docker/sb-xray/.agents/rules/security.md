# 安全规则

## 文件与代码安全

1. **不擅自删除文件**: 删除任何文件前必须明确告知用户并等待确认
2. **密钥不入库**: 配置文件中禁止硬编码密钥、Token、密码、证书私钥
3. **不跳过 Hook**: 禁止使用 `--no-verify` 绕过 pre-commit hook

## Git 操作安全

4. **发布前确认**: `git push`、创建 PR、发布 Release 前必须等待用户明确确认
5. **禁止强推主干**: 禁止对 `main`/`master` 执行 `git push --force`
6. **不 amend 已推送提交**: 已推送到远端的提交禁止 amend，应创建新提交

## 破坏性操作防护

7. **重置需确认**: `git reset --hard`、`git checkout .`、`git clean -f` 执行前必须确认
8. **评估爆炸半径**: 执行可能影响共享系统（远端仓库、容器镜像）的操作前，先评估影响范围并告知用户
