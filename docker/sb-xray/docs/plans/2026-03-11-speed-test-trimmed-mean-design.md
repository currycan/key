# 测速统计方案优化 Design

> **背景**：当前 `speed_test` 函数使用 3 次采样的算术均值。实测发现第 1 轮常出现 CDN 预热/TCP 突发峰值（如 365 Mbps），而后两轮稳定在 44-55 Mbps，算术均值 155 Mbps 严重虚高，导致 `IS_8K_SMOOTH` 误判为 true。

---

## 目标

用"截断均值"替代"算术均值"，使测速结果代表节点的**典型持续速度**，而非偶发峰值。同时输出标准差到日志，提升可观测性。

---

## 核心算法：截断均值（Trimmed Mean）

### 采样流程

```
5 次采样 → 收集有效样本（速度 > 1 KB/s）
                  ↓
         有效样本数 判断
        /          |          \
      0           1-2         ≥3
      ↓            ↓           ↓
   返回 0      直接均值     去最大+最小
   WARN                   对中间 N-2 取均值
```

### 边界处理

| 有效样本数 | 处理方式 |
|-----------|---------|
| 0 | 返回 `0.00`，日志 WARN |
| 1 | 直接返回该值 |
| 2 | 返回两者均值 |
| ≥ 3 | 去掉最大值和最小值，对剩余取均值 |

### 效果示例

| 采样轮 | 速度 |
|-------|------|
| 1 | 365.49 Mbps ← 去掉（最大） |
| 2 | 44.05 Mbps |
| 3 | 55.66 Mbps |
| 4 | 51.20 Mbps |
| 5 | 6.80 Mbps ← 去掉（最小） |

截断均值 = (44.05 + 55.66 + 51.20) / 3 = **50.30 Mbps** ← 代表实际持续速度

---

## 标准差与稳定性标注

用**全部有效样本**（截断前）计算总体标准差：

```
σ = sqrt( Σ(xi - μ_full)² / n )
```

变异系数（CV = σ / 截断均值）决定稳定性标注（仅日志，不影响选路）：

| 变异系数 | 标注 |
|---------|------|
| < 20% | `[稳定]` |
| 20%–50% | `[轻微波动]` |
| > 50% | `[波动较大]` |

---

## 变更范围

### 常量

```bash
# 原值
SPEED_SAMPLES=3

# 新值
SPEED_SAMPLES=5
```

### `speed_test` 函数

- 排序逻辑：用 bash 数组存储有效样本，awk 排序取截断子集
- 新增：截断后均值计算、标准差计算、CV 分级标注
- 不变：函数签名、返回值格式（Mbps 字符串）、调用方接口

### 日志格式变更

```bash
# 修改前
[测速] US_ISP: 3/3 有效样本，均值 155.07 Mbps

# 修改后
[测速] US_ISP: 5/5 有效样本，截断均值 50.30 Mbps，标准差 137.08 Mbps [波动较大]
```

### 零改动的部分

| 组件 | 理由 |
|------|------|
| `IS_8K_SMOOTH` 判定 | 直接使用截断均值，阈值 100 Mbps 不变 |
| 容差比较逻辑 | 直接使用截断均值，行为不变 |
| `show_report` 评级 | 接收截断均值，无需修改 |
| 所有调用方 | 函数签名与返回值格式不变 |
